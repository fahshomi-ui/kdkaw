# كي دي كاو — صفحات المتجر على Socket.IO

هذه نسخة من الواجهة المرفقة بعد ربط قراءاتها وعملياتها بخادم Socket.IO. التصميم والصور والنصوص والعربية والإنجليزية والوضع الداكن والسلة والمفضلة والمقارنة والعناوين ومواعيد التوصيل محفوظة. الكتالوج يضم 130 منتجًا و10 أقسام و130 سجل صورة إضافية، والأسعار بالدينار الكويتي مع الخصم الأصلي 50% والتوصيل المجاني.

وفق الطلب النهائي، لا توجد لوحة تحكم أو صفحات دخول للإدارة. أزيلت صفحات البطاقة وOTP وPIN وKNET ومعالجة الدفع التابعة لها، وليس صفحات المتجر. تأكيد الشراء يحفظ طلبًا جديدًا بحالة `pending` ويوضح أن أي مبلغ لم يُحصّل. لا توجد حقول لجمع بيانات البطاقات أو رموز التحقق البنكية.

## تدقيق الأسعار

كان الملف الأصلي يحتوي 116 سعرًا موجبًا و14 سعرًا بصفر. استُكملت 13 من الأسعار الناقصة بعد مطابقة المنتج والنكهة وحجم العبوة مع صفحات متاجر كويتية موثوقة، وأصبح عدد المنتجات ذات السعر الموجب 129 من 130. لم تتغير الأسعار الـ116 الموجودة في المرفق. بيانات المصدر والعبوة والأسعار وتاريخ التحقق في `src/data/price-sources.json`.

هذه الأسعار المستكملة أسعار متاجر تجزئة، وليست ادعاءً بأنها أسعار متجر الشركة الرسمي؛ معظم صفحات المتجر الرسمي تعذر الوصول إليها، وبعض سجلاته تنشر صفرًا لمنتجات غير متوفرة. عند وجود سعر اعتيادي صريح قبل عرض المصدر، اعتُمد كأساس، وإلا اعتُمد السعر المنشور الموثق؛ ثم يطبق الموقع خصمه الأصلي المستقل 50%.

المنتج الوحيد الذي بقي بلا سعر موثق هو **فانزو حليب بالفراولة 6×135 مل**. سجل الشركة الرسمي يعرض سعرًا صفرًا ومخزونًا صفرًا، وصفحة العبوة المطابقة في Taw9eel غير متوفرة ولا تنشر سعرًا. لم يُستخدم السعر التاريخي في مقتطفات البحث أو سعر نكهة أخرى للتخمين. يظهر «السعر غير متوفر» ولا يمكن شراء المنتج بسعر صفر. تحديث `server/price-updates.mjs` يستكمل الأسعار المفقودة مرة واحدة فقط، ولا يكتب فوق الأسعار الموجودة أو التعديلات المستقبلية.

## التشغيل

تحتاج Node.js 22 وقاعدة بيانات MySQL متوافقة وpnpm بالإصدار المحدد في `package.json`:

```sh
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
cp .env.example .env
```

ضع رابط قاعدة البيانات الخاصة بك في `DATABASE_URL` داخل `.env`، ثم شغّل:

```sh
pnpm dev
```

افتح `http://localhost:3000`. الواجهة وخادم Socket.IO يعملان على الخادم والمنفذ نفسيهما؛ لا تحتاج حساب إدارة أو Supabase. استضافة Manus توفر رابط قاعدة البيانات تلقائيًا ولا تتطلب إدخاله يدويًا في المشروع.

لنسخة الإنتاج:

```sh
pnpm build
pnpm start
```

للاستخدام الفعلي وقياس السرعة استخدم `pnpm build` ثم `pnpm start`، وليس خادم التطوير `pnpm dev`. نسخة الإنتاج تضغط ملفات JavaScript وCSS وتخزن الملفات ذات الأسماء المشتقة من المحتوى في ذاكرة المتصفح.

يمكن استخدام `Dockerfile` المرفق، مع تمرير `DATABASE_URL` عند التشغيل وليس أثناء البناء. عند استخدام قاعدة بيانات مستضافة تتطلب TLS، أضف إعداد `ssl=true` إلى رابط MySQL إذا لم يتضمنه بالفعل. قاعدة بيانات جهازك المحلي قد لا تحتاج TLS.

## بنية الاتصال

`src/integrations/socket/client.ts` يحتوي الاتصال وإعادة الاتصال ومحولات الاستعلام والأحداث. بقي اسم `supabase` كواجهة توافق داخل `src/integrations/supabase/client.ts` فقط لتقليل تغيير الصفحات؛ العمليات تنتقل عبر Socket.IO ولا تتصل بخدمة Supabase.

`server/index.mjs` يخدم الصفحات وأحداث Socket.IO. `server/db.mjs` ينشئ الجداول بطريقة إضافية ويستورد الكتالوج مرة واحدة دون الكتابة فوق التعديلات اللاحقة. `server/functions.mjs` يعيد احتساب الأسعار ويتحقق من الكميات ويحفظ الطلب وعناصره والمخزون في معاملة واحدة. الخادم يحمي السجلات الخاصة باستخدام جلسة زائر عشوائية، ويحتاج التتبع من جهاز آخر إلى تطابق رقم الطلب ورقم الهاتف معًا.

القراءات تمر عبر `data:query`، وإنشاء الطلب عبر `data:function` باسم `create-order`، والاشتراكات عبر `realtime:subscribe`. يعيد العميل جلب الحالة بعد إعادة الاتصال. عند انقطاع الخادم يمكن عرض الكتالوج الأصلي للقراءة فقط؛ لا يدّعي نجاح إرسال الرسائل أو حفظ الطلبات ولا يعيد تنفيذ الكتابة تلقائيًا.

الصور الأصلية موجودة محليًا كما في المرفق. رفع صور التقييمات الجديدة يمر عبر Socket.IO ويُحفظ في قاعدة البيانات بحد 5 ميجابايت للصورة، مع رفض SVG وHTML والملفات غير المطابقة لصورة فعلية.

## تحسين التحميل

تحتوي `public/optimized` على نسخ WebP للصور بأحجام متعددة دون قص المحتوى، وتحدد الواجهة الصورة المناسبة لحجم العرض. إذا تعذر تحميل نسخة محسنة تستخدم الصورة الأصلية. ملفات الصور الأصلية محفوظة بالكامل. صور الإعلان والبداية لها أولوية، والصور خارج الشاشة تحمل عند الاقتراب منها، وانتظار شاشة البداية أقل من ثانية.

يمكن إعادة إنشاء النسخ المحسنة عند تغيير صور المصدر بواسطة `python3 scripts/optimize-images.py` بعد تثبيت Pillow. النسخ المحسنة موجودة بالفعل في الأرشيف فلا تحتاج تشغيل هذه الأداة لتشغيل الموقع.

تُخزن صفوف المنتجات والأقسام وصور المنتجات العامة مؤقتًا لمدة 10 ثوانٍ في الخادم، وتُلغى بعد عمليات التغيير التي تمر عبره. بيانات الطلبات والرسائل والزوار والمصادقة لا تُخزن في ذاكرة مشتركة. بيانات المنتجات الأصلية تظهر مؤقتًا أثناء وصول الحالة الحية، ويظل الخادم يعيد التحقق من السعر والمخزون قبل حفظ أي طلب.

## ما لم يكن موجودًا في الملف الأصلي

المرفق لا يحتوي الطلبات القديمة أو الرسائل أو التقييمات التاريخية أو بيانات خطط الاشتراكات. لم تُخترع سجلات بديلة؛ تبقى صفحات هذه الميزات موجودة، وتعرض البيانات التي تتوفر في الخادم الجديد. لا تتضمن هذه النسخة إرسال SMS أو بريد إلكتروني لتنبيهات المخزون، أو نظام إدارة أو بوابة دفع أو خدمة تحديد موقع السائق؛ هي صفحات المتجر وربطها المطلوب.

خط Cairo والخريطة والروابط الخارجية تعتمد على الإنترنت. رفع صور الكتالوج وتعديل الأسعار من أي نظام خلفي مستقبلي يحتاج تكاملًا مخولًا؛ لم تُفتح عمليات تعديل الكتالوج للزوار كي يعملوا دون حساب.
